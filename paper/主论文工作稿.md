# 有限提前期情景下多级库存配置：经验缓冲与静态鲁棒性的探索

**工作稿；不具备投稿条件。** 作者、目标期刊、数据授权、独立验证与人工逐项核验均待确定。研究为事后探索，不声称预注册或新的鲁棒优化算法。

## 摘要

多级库存配置模型依赖不同保护期的需求缓冲曲线。本文以 Willems 案例01的八节点网络为结构基准，将三个不同来源的销售或订单序列分别映射至末端需求，比较正态、滚动经验及二者包络曲线下的保证服务模型。数据映射为半合成构造，网络、销量、成本和日历并不属于同一企业。针对经验与包络曲线的期限拆分性质，进一步构造非减离散凹主化曲线，并比较配置及模型目标。在每种曲线的48条节点曲线中，经验和包络各26条在某些期限拆分下不满足次可加性，正态曲线未检出；该性质不单独证明模型无效。对24组经验或包络的修正模型，约化枚举与对应混合整数规划目标一致；在给定数值容差下，11组未找到修正前后共同的约化最优配置。对当前拓扑、非减曲线及非负权重，可通过服务时间规范化将完整共同最优解映射至该约化集合。双源提前期的12组互斥情景分析中，所保存的名义和鲁棒规范代表有2组不同；在其余10组中相同。相应盒式和互斥鲁棒代表在12组均相同，但这不表示完整最优解集相同；这些组合共享网络与数据来源，并非12个独立企业样本。[E51] 既有外部序列的评价时段已参与探索；此前隔离的2026年3月零售销售记录日窗口历史留出检验显示，不同门店的超界次数存在差异；经验与主化两条曲线在222对匹配窗口的超界指示完全相同。[E15,E44] 窗口重叠，样本与营业语义未确认，尚不能证明未来服务改善或实际成本下降。[E1–E4]

**关键词：** 多级库存；静态鲁棒优化；有限情景；保证服务模型；需求缓冲

## 1. 引言与研究问题

保证服务模型通过不同环节的服务时间配置安全库存。[6]实际应用中的需求边界构造涉及保护期、序列特征与有限样本；有限样本滚动分位曲线不必具有研究者希望的所有形状性质。本研究关注以下可检验问题：在固定网络、服务约束和需求映射下，经验需求缓冲曲线的构造及其非减凹主化，是否改变库存配置的模型最优值和共同最优配置？同时，在双源提前期的互斥与盒式情景下，比较共享决策的最坏目标及其与名义配置的权衡。反对解释包括：保存方案差异仅来自等优解；模型目标变化依赖曲线修正、需求尺度和人为情景，不对应真实服务或财务改善。[E1,E3,E36]

Humair 等（2013）已在 Willems 案例01中研究 Part_0001 的随机提前期，并同时考虑安全库存与提前到货库存；其阶段期望库存目标可以非凹。[14] 本文的有限场景静态极小极大模型不估计提前期分布，也未建模提前到货库存，因此案例01、提前期不确定性或非凹性本身均不能作为本文的创新性证据。Svoboda 与 Minner 的机构摘要及作者博士论文总结显示，其方法从外部特征学习基库存，考虑服务约束及样本外模型成本；正式期刊论文尚未逐式核查，不能仅凭摘要排除其研究与本文其他方面的重叠。[3] [E43]

本研究的规范化证明针对案例01的特定结构；对38个原始完整网络的拓扑扫描显示，只有案例01本身具有相同的8节点、10弧规模，其余案例需要另行验证适用条件。此结构差异不排除构建更一般的约化方法。[E9]

该问题是基于既有数据发现后的探索。Beiran 等在保证服务模型中研究箱形不确定集下的提前期与库存配置，并对 Willems 案例库前20条网络开展实验；Svoboda 与 Minner 研究基于特征和数据驱动的多级库存配置。[2,3]本文当前考察经验期限曲线及其凹主化对配置比较的影响，但这一区别尚不能证明新颖性：前者的公开全文已进行针对性比较，后者期刊论文目前主要依据作者机构摘要，尚须取得全文逐式核验。故“鲁棒”“数据驱动”或使用 Willems 网络本身均不足以确立贡献。[E5,E6] Humair 与 Willems (2011) 已研究一般无环网络中可以非凹的阶段成本；Blaettchen 等 (2026) 进一步提出面向一般无环网络和阶段服务时间成本的精确线性规划方法。其正式版允许有界服务时间上的一般节点成本，还讨论随机处理期成本及节点子集的总基库存上限；其节点可加目标与本文跨情景总成本取最大值的鲁棒目标之间是否可直接等价，需要另行证明。Moncayo–Martínez 与 Mastrocinque 已在正态需求下为38个案例获得整数解，其中17个报告求解最优，后续作者发布对应计算数据；因此经验曲线非凹、案例拓扑、有限选择编码或单独加入上限，都不能作为一般性算法创新。[4,5,15,16] [E48]

## 2. 数据和模型

### 2.1 网络及需求来源

使用 Willems 案例01网络，包含三个零件、两个制造和三个零售节点，共10条弧。[1]案例参数经处理，标准化弧系数并非可直接解释为某企业真实 BOM。分别使用 UCI Online Retail、SupplyGraph 和意大利门店序列构造末端销量或订单代理。[7–9]每个来源分别映射和缩放，三者并非同一供应链。销售受到库存、退货及营业日等因素影响，不能无条件等同潜在需求。周末销量分别采用并入下周一和仅保留工作日的两种代理，真实营业日历未知。[E1,E7]

本研究的曲线拟合期与已接触的后续评价期如下，日期均包含两端；后续期已经参与探索，不作为盲测。[E31]

### 2.2 服务时间与目标

对节点 i，令入站服务时间为 SI_i、出站服务时间为 S_i、处理时间为 T_i；案例01主实验中 SI_i 与 S_i 均为非负整数，单位为假定工作日，整数净保护期为 τ_i=SI_i+T_i−S_i≥0。DataCo补充分析改用自然日。对弧 (i,j)，要求 S_i≤SI_j，并施加源点、末端及特定节点的服务时间上限。给定节点权重 h_i 和需求缓冲曲线 b_i，最小化 Σ_i h_i b_i(τ_i)。权重依据案例标准化增值与假定持有系数生成，不作为实际货币成本。处理时间确定近似与有限提前期压力设定沿用已存模型；比较各方法时固定相同可行域和其他输入。[E1,E8]

以协方差正态近似、连续滚动窗口经验分位和两者逐点最大值构造三类缓冲曲线；经验曲线事先取期限累计最大以保证单调。对经验和包络曲线，检查各有限整数期限上 b(a+b)≤b(a)+b(b)，随后事后构造逐点不低于原曲线的非负、非减离散凹主化：令 v(0)=0，约束 v(t)≥b(t)、增量非负且非增，并最小化各正期限 v(t) 之和。在本文非负非减输入、零初值与对所有正期限等权求和的设定下，该线性规划的解唯一，等于原曲线的逐点最小非减凹主化；这一性质不意味着相应库存配置唯一，也不自动提供需求覆盖的概率保证。[E2,E24]

设 $X_d$ 为缩放后的三个末端日需求，$\mu=(253,45,75)$，$\Sigma$ 为训练期同日样本协方差，$a_i$ 为节点的路径传播系数，$z_{0.95}=1.6448536$。正态缓冲取 $b_i^N(t)=z_{0.95}\sqrt{t\,a_i^\top\Sigma a_i}$，将跨日累计方差按 t 倍同日协方差近似；经验缓冲先以完整训练滚动窗口总需求的0.95分位减去 $t a_i^\top\mu$、截断为非负，再沿期限累计取最大。分位采用 NumPy 的 `higher` 顺序统计约定，各期限至少要求20个训练窗口；包络取二者逐点最大。重叠窗口和单期限经验分位不构成全网联合95%服务保证。以60个假定工作日的期限为例，三来源、两种日历下的训练窗口数为35—69；在累计最大修正前，0.95的 higher 分位上方仅有1—3个顺序统计位置。窗口彼此重叠，该数量既不是独立样本量，也不能直接推断覆盖率或置信区间。[E31,E44]

实际整数规划令二进制 $z_{ik}$ 指示节点 i 的净保护期为 k，约束 $\sum_{k=0}^{M_i}z_{ik}=1$ 和 $SI_i+T_i-S_i=\sum_{k=0}^{M_i} k z_{ik}$，目标为 $\min\sum_i\sum_k h_i b_i(k)z_{ik}$；再施加前述网络弧、源点与末端边界、$0\le SI_i\le M_i-T_i^{max}$、$0\le S_i\le M_i$ 及 Part1 的 $S\le20$。其中 $M_i$ 由最大处理期最长路径构造。名义与压力模型分别固定 Part1 处理期为28和50；既有 {20,25,50} 为另一有限情景检查，28不属于该集合。详细权重、路径系数、窗口数和代码对应见方法补充。[E31]

对于有限提前期集合 $U=\{20,25,50\}$，固定同一组服务决策 $x=(SI,S)$，静态鲁棒版本为 $\min_{x\in D_{all}}\max_{u\in U}\sum_i h_i b_i(SI_i+T_i(u)-S_i)$，其中 $D_{all}$ 要求每个情景的净保护期与网络约束均可行。由于仅 Part1 处理期变化、权重非负且缓冲曲线非减，固定可行方案的最坏目标由50期产生；又因该源点 $SI=0$ 且 $S\le20$，20期非负保护期自动满足，现有其余上下界保证三个情景均可行，故本案例的静态极小极大问题等价于上述50期模型。一般情况下最坏情景的可行域不必包含所有其他情景的可行性；此化简不构成一般可调鲁棒或分布鲁棒模型。[E32]

作为另一事后扩展，设两个源节点处理期为 $T_1=28+22\delta_1$、$T_2=15+10\delta_2$，其中 $\delta_i\in\{0,1\}$ 且 $\delta_1+\delta_2\le1$。三个有限情景分别为 (28,15)、(50,15)、(28,25)，表示假设最多一个源节点出现给定幅度的延迟；并以包含 (50,25) 的盒式情景作对照。两类模型共用同一组服务时间决策及共同可行域，对每个情景的净保护期分别施加边界，且按最大处理期重新计算期限上限。该互斥约束为研究假设，不是由故障数据估计的相关性或概率。[E36]

### 2.3 计算与约化交集

在案例01中，三个Part均连接两个Manuf；两个Manuf再连接三个Retail。给定非负权重和非减缓冲，任一可行服务时间方案可规范化，使三个Part出站的最大值为 q，两个制造节点的出站为 m1、m2；映射不会增加任一节点净保护期。故共同最优方案存在与否，可在 q=0,…,20、m1,m2=0,…,q+10 的10,031个约化三元组中判定。数值实验以绝对容差0.0001判断共同最优，并用0.001复核；这不是对其他拓扑或非单调目标的通用定理。独立审阅检查了本案例的服务时间边界与映射；缩小同拓扑网络的穷举为这一论证提供辅助核验，而非对原案例完整域的穷举。非单调缓冲及负权重分别存在反例。[E3,E30]

对原曲线和主化曲线的目标 $f_1,f_2$ 及各自最优值 $f_1^*,f_2^*$，令 $X_R$ 为案例01的10,031个规范三元组，补充计算 $\rho^*=\min_{x\in X_R}\max_{j\in\{1,2\}}\left\{\frac{f_j(x)-f_j^*}{\max(1,|f_j^*|)}\right\}$。本研究中各目标最优值均大于1。在数值误差允许范围内，若 $\rho^*\le\epsilon$，存在同一约化配置使两个目标各自相对退让不超过 $\epsilon$；该量只度量当前模型的两个目标权衡。[E37]

既有案例01主实验的记录环境为 Windows Python 3.13.17、NumPy 2.5.4 和 SciPy 1.18.1；部分历史脚本会将本机 `tools/python` 加入搜索路径，该目录中的二进制依赖与 Python 3.12 不兼容。工程原型此前在 Python 3.12 的测试不能单独证明案例01论文脚本在该环境可重跑。另一个不覆盖原结果的探针在预加载本机 Python 3.12 依赖后复算4个模型，与保存目标最大绝对差约8.73×10⁻¹¹；它只覆盖原36模型中的4个，不构成完整或隔离环境复现。另将双源有限情景模型整理为本机Python 3.12的工程安装包；12组24次求解与既有保存结果的最大绝对差约1.88×10⁻⁹，12个固定策略在48个人为情景上的目标回放与保存结果一致。前者使用同一派生曲线及HiGHS，后者不是重新优化或现实外测；两者不等同于36个原始主模型从原始数据的完整独立复现。另在0.8.0安装版以同一假设、数据和算法重放一条255日合成物料流路径，36,465个状态及累计账本字段与研究版相符；这只覆盖一条路径，不构成独立企业或模型外部验证。完全隔离依赖和跨平台复现仍待完成。[E31,E40,E45,E53]

## 3. 探索结果

### 3.1 期限曲线形状及最优配置

三个数据源、两种假定工作日日历及8个节点共同形成每类方法48条期限缓冲曲线。正态曲线未检出次可加性违反；经验曲线及包络曲线各有26条在检查的有限期限分解中至少违反一次。曲线和节点来自共享数据与网络，不是48个独立企业样本；检出违反也不意味着保证服务模型必然无效。[E2]

对经验与包络曲线分别在28、50期比较原模型与非减凹主化模型，共24组。主化目标相对原目标的变化及给定绝对容差下的共同最优检验分来源见表2；由于主化曲线逐点不低于原曲线、模型可行域相同，最优目标不降低是构造上的结果。两类目标均采用假定节点权重，不能解释为真实货币成本。[E2,E3,E31]

### 3.2 提前期情景的静态鲁棒性

先以单源有限集合 {20,25,50} 比较共享服务时间决策的显式极小极大模型与50期模型。三来源、两种日历及经验/包络曲线共12组均由求解器报告最优，目标最大绝对差约8.87×10⁻⁸；对每组规范配置枚举最坏情景目标后，二者最大差约2.33×10⁻¹⁰。此结果是本案例“权重非负、曲线非减、共同可行域相同”条件下的情景支配核验，不表示可将一般多维鲁棒问题化为单一情景。[E32]

双源互斥扰动情景 (28,15)、(50,15)、(28,25) 中，12组有6组在不同可行配置下出现扰动A、B目标排序反转，另6组没有出现反转；因而非嵌套参数本身不必然导致最坏目标切换。与最多一个源节点扰动相比，增加同时扰动 (50,25) 的盒式模型在 SupplyGraph 4组的假定加权缓冲最优目标高约1.161%—1.663%，其他8组在数值容差内相同。集合扩大后最优目标不降低是模型结构性质，而非实测故障成本。[E36]

在上述12组中，静态极小极大值均与共同可行域内各单情景最小目标的最大值相等，按此最坏目标口径未观察到非预见性代价；这不意味着存在一个配置同时对所有情景最优：意大利门店仅工作日日历下，经验与包络两组在绝对容差10⁻⁴和10⁻³时均未找到同时对三个单情景近似最优的规范配置；这一结论仍依赖案例01的规范化条件和数值容差。上述结果也不说明此性质适用于其他数据。24个相关MILP均由求解器报告最优，另以规范域枚举重算；情景幅度和互斥关系为研究假设，非估计的故障概率或相关性。[E36]

对12组进一步在共同可行域内独立重算名义与互斥鲁棒代表的交叉目标。只有意大利门店仅工作日的经验和包络两组保存的规范代表不同，其余10组相同；这两组共享同一来源，不能当作独立企业。以经验曲线为例，鲁棒代表的名义目标比名义最优高约1.380%，名义代表的三情景最坏目标比鲁棒最优高约4.228%；后者以鲁棒最优为分母，若以名义代表的最坏目标为分母计算降幅则为约4.057%。两指标均为假定加权缓冲的模型内权衡。12组保存的互斥与盒式最优规范代表均相同，不能据此推断完整最优解集相同，也不能把盒式目标上升理解为保存代表配置改变。上述复算覆盖120,372个规范配置，完整域解释仍依赖案例01的规范化条件。[E51]

### 3.4 新来源与其他网络的边界检查

DataCo 补充分析使用2015—2016年训练期选出的三个产品与案例01的假设网络[13]；与前述工作日日历不同，此处采用自然日。经验和包络曲线各8条均未检出所检查的次可加违反；28、50日期的四组原/主化比较均有共同约化最优见证，不并入表2的24组。[E34]

这三个产品在2017年各有275天存在订单记录，最后90天同时无记录。预设全年评价将无记录日按零记录订单量处理，可能低估代理，不能据此确定真实需求；事后仅保留全窗口三产品均有记录的终点，经验曲线28、50日期的等预算平均代理差分别约+0.2138、−0.8607。两种保存配置的保护期相同，不应计为独立重复。进一步仅在评价时排除取消与疑似欺诈订单，经验28日情景下两代理均值从约155.12、154.91降至0.92、1.11；仅保留 COMPLETE/CLOSED 时均为零。训练曲线仍包含全部状态，筛选改变评价数量尺度，状态含义和可用时点未知，因此该变化只说明代理对评价口径敏感，不能判定真实需求、库存改善或策略优劣。[E34,E35]

为检查上述训练与评价口径不一致的影响，进一步对相同商品分别按状态筛选重建训练序列、缩放、曲线并重求模型，统一使用50日历史窗口和226个记录完整终点。经验曲线28日情景、排除取消及疑似欺诈时，仅筛评价的两项代理均值约为1.005和1.213，训练与评价同口径重拟合后为87.225和89.297；仅保留 COMPLETE/CLOSED 时分别由0、0变为30.141和28.555。中间对照中，仅按筛选后训练均值调整评价缩放、保留旧曲线和决策，也产生较大变化；同口径重拟合同时改变缩放与曲线，不能作单因素因果解释。这一统一50日窗口不同于前述28日情景的248个终点，不可直接比较数值；状态可得时点和业务含义仍未确认。[E38]

另一事后交叉检验固定同一缩放系数，分别以三种状态口径训练并评价。对任一固定训练模型与缓冲，筛除非负订单使所定义的正超界代理不增加，是该指标的单调性质，不能解释成库存策略改善；按不同状态重新拟合后阈值和目标又会改变。当前派生数据只有订单日期和最终状态快照，没有状态生成或变更时间，因此无法判断训练截点时该状态是否已知，也不能据此断言一定发生了信息泄漏。[E39]

案例02、03的附加分析为不同结构和约束下的事后敏感性，而非案例01证明的直接推广。案例02中，30期经验与主化目标约相等并找到共同最优见证；45期假定压力下，主化目标较经验高约4.59%；当经验目标限制在自身最优值的1.00001倍以内时，主化目标的受限最小值约为自身最优值的1.072倍，因此在求解器数值容差下未找到两个目标均在各自最优值0.001%以内的共同方案。案例03中，部分原模型达到求解时限，后续固定0.1日网格的压缩模型对有关三项均由求解器报告零间隙；不同门店和情景既有共同最优见证，也有尚待数值审计的情况。末端80/60/40日净保护期上限是人为情景，其结果不代表已观测仓储容量。[E10,E11,E19,E20,E22,E23,E25]

三月三店、1/7/14日的历史留出检验进一步将经验与主化阈值逐日配对：222对窗口中，147对阈值相同，75对阈值不同，但所有超界指示相同。不同窗口高度重叠，222并非独立样本数；这一零差异既不证明两方法等效，也不能证明现实服务改善。[E15,E44]

另构造合成案例01物料流，在已暴露的意大利销售记录路径上比较名义与鲁棒规范方案。首次浮点实现的16个策略、目标映射和情景组合均因数值或守恒检查中途失败；随后事后改用单独的十进制实现，保持输入与方案不变，16条路径完成。对90日预热后的165日评价期，四种处理期情景下，名义/A、名义/B及鲁棒/A或B的模拟订单同日满足率分别为100.00%、99.52%和98.93%；鲁棒A、B目标与轨迹相同。三个组合的假定加权库存位置目标分别约为295,570.82、222,188.82和213,641.10，预算并未配平，故上述差异不能归因于鲁棒性或解释为等成本下优劣。独立有理数审计复核4,080个模拟日的保存账本、固定处理期和48项预热汇总，但未逐笔重建内部队列。BOM及库存目标映射是额外假设，原销量不是已知潜在需求，模拟同日满足不是企业真实缺货或保证服务水平。[E49]

查看上述结果后，事后将四个策略—映射的库存位置目标按各自统一比例放缩，使假定加权目标总和在数值容差内一致，再对同一路径和四种情景模拟。由于鲁棒A/B目标相同，四个标签实际对应三种目标，共12条唯一轨迹；按三档预热展开的48个标签汇总中，模拟订单的同日满足率均为100%，不能据此证明现实服务等效。在90日预热下，鲁棒减名义的假定加权日末成品在手均值差，映射A的四情景约为+34,198—+34,876，映射B约为+2,022；此代理不包括投入池与在制，不是总持有成本。按目标加权总和配平并未重新优化或保证相同实际库存、费用和运营可行性；该事后敏感性也无法单独识别鲁棒性、目标分布或映射的因果效应。[E52]

所有历史评价均为半合成、已接触的销售或订单代理，窗口和节点彼此相关。未找到共同窗口不计为零；未检出次可加违反或观察到零超界也不构成服务概率保证。三月、四月零售门店数据[10]、库存区间切分、缺记录替代值与同候选双指标支配分析的具体结果保留在补充材料中。[E4,E13–E18,E21,E26,E28]

## 4. 讨论

本案例表明，经验曲线的形状处理可能改变优化结果；它不表明未主化曲线必然使保证服务模型失效，也不表明凹主化实现更好的实际服务。比较结果可能受到销售代理、时间映射、尺度调整、数据分布变化及多重最优影响。规范化论证解决了当前拓扑和目标下的共同最优存在性，而不证明某种曲线在其他网络、需求分布或约束下优于另一种。

训练序列的事后扰动也显示当前案例结果对数据构造敏感。以 UCI 选定商品、仅工作日日历和经验曲线为试点，同步循环重采样5日或10日块各50次，每次重新计算尺度、经验缓冲及凹主化，再对同一规范域求解。按每个目标绝对差不超过10⁻⁴判定共同近似最优，原样本的28、50日情景均未找到共同配置；5日块各有12/50次找到，10日块分别有16/50和15/50次找到。这些次数只描述人为扰动而非统计概率。块拼接制造非历史相邻关系，5/10日又远短于最长60日保护期，无法保留长期依赖；重新缩放还改变每次半合成输入，故该试点既非独立外测，也不能构造可信区间或证明现实策略不稳定。[E46]

进一步作事后长块对照时，30、60、90日块各预定50次；其中分别有2、1、0次因商品23166重采样均值为零而无法按既定方法缩放，未被替换或当作零目标。在可拟合重复中，28日情景分别有14/48、10/49、9/50次找到共同近似配置；50日分别为12/48、10/49、9/50。这些是条件于可拟合样本的描述，存在选择偏差。每次69个60日窗口中，原始工作日行号完全连续的窗口数中位数对5、10、30、60、90日块依次为0、0、0、1、24；循环首尾及不同块拼接均可能破坏历史相邻性。因此更长块也未消除有限历史与人工拼接问题，无法据此构造可信覆盖区间。[E47]

已有文献也提示，不宜把物料流仿真或额外约束本身作为新颖性依据。Klosterhalfen 等将需求超出边界时的加急纳入安全库存配置；本文合成回放采用完全欠交且未设置加急机制。Acar 与 Gunter 在另一多地点多级生产网络中结合仿真与优化，并考虑供应和产量柔性及提前期不确定性；其业务与信息结构不同，相关文献目前按可访问内容作定向比较，尚需对全文逐式核查。[17,18] [E50]

固定方案评价也不能单独识别整个期限缓冲函数。以 DataCo 状态敏感性中24份保存方案为例，Retail_0001 的净保护期均为0；数学上将该节点原曲线与凹主化曲线同时乘2，0期值保持不变，保存方案的目标和固定配置代理均不变。由于新曲线逐点不低于旧曲线、权重非负，原保存最优方案仍为最优，其他等优方案是否保留则不确定。该反例不是根据相同订单重新拟合出的实证曲线，只说明现有固定方案输出不足以识别未访问期限的曲线形状。[E41]

近期研究也提示需要区分模型对象。Leng 等的动态分布鲁棒库存预印本将最小凹主化用于需求变量上的成本/延续值函数，而本文主化的是保护期限索引的经验缓冲曲线，二者的假设和目标不同；本文的凹主化不由此得到分布鲁棒保证。[12] Vicente 的多期库存规划显式建模库存平衡、失销及成本，其运营指标与本文静态销售超界代理不能直接等同。[11] 相关文献的可访问范围和公式比较见独立核查报告。[E33]

数据与评价的主要限制是：网络和外部销量不是同一企业，真实 BOM 与库存不可得；营业日未知；已查看的评价窗口彼此重叠；测试与方案选择没有完全隔离。汽车动态模型是不同数据与问题，可另作补充研究，不能将其订单延期与本模型目标合并。未来如验证预期效果，需在读取未参与方案选择的时间段之前固定数据处理、候选方法和共同评价指标，并报告所有来源、无改进结果及独立样本单位；若库存与成本语义缺失，仍只能声称销售代理检验。[E1,E4,E7]

## 5. 结论

在当前案例、有限提前期情景和数值容差下，名义与互斥鲁棒方案所保存的规范代表在12组中有10组相同、2组不同；互斥与盒式鲁棒的保存代表在12组中均相同。这些组合共享网络及数据来源，不能视为独立企业，也不能据此判断完整最优解集是否一致。经验缓冲曲线的非减凹主化在部分组合中改变共同最优配置是否存在。[E2,E3,E51]

对单一已暴露历史路径进行的事后仿真中，在人为放缩至相同假定加权目标后，所有预设情景的模拟订单同日满足率均为100%；该结果不证明策略现实等效，也不能说明真实服务或成本变化。模型情景、BOM、目标映射及权重仍为假设，本研究尚无充分依据断言方法具有普遍优越性或已满足高质量期刊投稿要求。[E49,E52]



完整的逐组结果、不可评价情形、数据处理、复现代码及审计更正见本地补充材料索引（当前未公开）；内部证据编号和数据许可仍须按目标期刊要求整理。
